# Nerowa Cases

Tienda en linea de un solo producto: estuches para dos arcos de contrabajo.
Un modelo, catorce colores de catalogo, 180 EUR. Despacho desde Vilnius.

- **Mercados:** Union Europea y Reino Unido.
- **Idioma del sitio:** ingles, sin selector de idioma.
- **Prioridad:** movil primero. Casi todo el trafico llega de Instagram, en telefono, con datos moviles.
- **Pago:** pagina alojada de Stripe. El checkout no se disena.

## Estado

El proyecto esta en construccion. El avance paso a paso se lleva en [`progreso.md`](./progreso.md).
La especificacion de estructura y comportamiento esta en [`docs/estructura-web.md`](./docs/estructura-web.md).

## Convenciones

- Todo cambio entra por un pull request nuevo contra `main`.
- Espaciado en multiplos de 8. Escala tipografica consistente.
- Contraste WCAG AA en todo texto.
- Cero fotos de banco de imagenes, cero ilustraciones genericas.
