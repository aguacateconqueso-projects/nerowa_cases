# Imagenes

Fotos y graficos del sitio. Todo lo que este aqui se sirve tal cual desde la
raiz del dominio: `public/images/estuche.jpg` se pide como `/images/estuche.jpg`.

## Como subir

Arrastra los archivos a esta carpeta (o subelos desde GitHub con
**Add file > Upload files**) y avisa que estan; desde ahi se colocan en la
pagina que toque.

## Recomendaciones

- Nombres en minusculas, sin espacios ni acentos: `estuche-negro-frontal.jpg`.
- Formato `.webp` o `.jpg` para fotos, `.svg` para graficos planos.
- Lado largo maximo de 2000 px. Casi todo el trafico llega por telefono con
  datos moviles; una foto de 8 MB frena la pagina.
- Nada de bancos de imagenes.
